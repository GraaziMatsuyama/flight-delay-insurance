# flight-delay-insurance
CA1 Distributed Digital Transactions — flight delay insurance using Solidity smart contracts.

## About the project
This project will use a Solidity smart contract to manage
insurance claims for delayed flights.

A customer purchases a policy before the flight. An authorised
account reports the delay, and the contract checks whether
the customer can receive compensation.

## Main rules
- A delay of 120 minutes or more qualifies for compensation.
- Only an authorised account can report the delay.
- Each policy can receive compensation only once.
- The project uses simulated flight information and test funds.

The 120-minute limit is a fictional rule chosen for this project.

## Progress
The project is currently in the planning stage.
